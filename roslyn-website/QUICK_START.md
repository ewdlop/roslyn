# 🚀 快速啟動指南

## 最簡單的方式

### Windows 用戶
1. 雙擊 `start.ps1`（需要 Python）
2. 或直接雙擊 `index.html` 在瀏覽器中開啟

### macOS / Linux 用戶
1. 在終端機中執行：
   ```bash
   chmod +x start.sh
   ./start.sh
   ```
2. 或直接在瀏覽器中開啟 `index.html`

## 其他啟動方式

### 使用 Python（推薦）

**Python 3:**
```bash
python -m http.server 8000
```

**Python 2:**
```bash
python -m SimpleHTTPServer 8000
```

然後訪問：`http://localhost:8000`

### 使用 Node.js

```bash
npx http-server -p 8000
```

### 使用 PHP

```bash
php -S localhost:8000
```

### 使用 VS Code

1. 安裝 "Live Server" 擴展
2. 右鍵點擊 `index.html`
3. 選擇 "Open with Live Server"
